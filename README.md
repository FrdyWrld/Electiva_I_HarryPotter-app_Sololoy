 Breve descripción del proyecto.

 **HarryPotter-app** es un proyecto universitario para construir una aplicación web desde cero utilizando **React con TypeScript y Vite**, diseñada para consumir la API pública de HarryPotter  y presentar la información con una interfaz clara, tipada y tolerante a errores[1].

Sus pilares y requerimientos principales se dividen en:
* **Funcionalidad básica (Requisitos Funcionales)**:
  * **Listado inicial**: Muestra al menos 20 elementos con tres datos cada uno[4].
  * **Búsqueda con filtro**: Input controlado con un retardo manual de 400 ms mediante `setTimeout`[4].
  * **Vista de detalle**: Despliega información adicional al seleccionar un elemento y permite regresar al listado[4].
  * **Gestión de favoritos**: Permite marcar/desmarcar libros, con contador visible y persistencia en `localStorage`[3].
  * **Reintento de peticiones**: Ofrece un botón para reintentar la conexión si ocurre un error sin recargar la página

Instrucciones de compilación y ejecución.
Se ejecuta con npm run dev 

## Instalación y ejecución

### 1. Clonar el repositorio
 
```bash
git clone https://github.com/FrdyWrld/Electiva_I_HarryPotter-app_Sololoy
```
 
### 2. Entrar en la carpeta del proyecto
```bash
cd Electiva_I_react-openlibrary-app_Sololoy
```
### 3. Instalar las dependencias

```bash
npm i
```
 
### 4. Ejecutar en modo de desarrollo
 
```bash
npm run dev
```
### 5. Compilar el proyecto
 
```bash
npm run build
